# dsa-leetcode
Solutions to LeetCode problems in Python and C++, each with a beginner-friendly explanation of the approach.

I'm learning data structures and algorithms by teaching them. For every problem
I write up the reasoning in plain language — if I can't explain it simply, I
don't understand it yet.

## How this is organised

Problems follow [Sean Prashad's LeetCode Patterns](https://seanprashad.com/leetcode-patterns/),
worked through in order starting from the beginner set. The list is grouped by
pattern rather than by problem number, and this repo mirrors that.

Each problem folder contains:

- `solution.py` — Python solution
- `solution.cpp` — C++ solution
- `README.md` — the problem, the approach, and why it works
